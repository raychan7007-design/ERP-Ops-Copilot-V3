# 3分钟面试Demo脚本

1. **采购诊断**：输入 `PO100为什么还是部分验收？`，展示SQL查到 ordered=5、received=3、remaining=2，并给出规则原因。
2. **销售诊断**：输入 `SO100为什么不能出库？`，展示订单需求5、库存3，解释库存不足拦截。
3. **数据查询**：输入 `SKU002现在库存多少，最近发生了什么？`，展示库存16和最近入/出库流水。
4. **知识问答**：输入 `为什么库存余额还需要库存流水？`，展示RAG返回“余额解释结果、流水解释过程”并给文档来源。
5. **UAT辅助**：输入 `新增分批验收功能，允许多次到货但累计不得超过采购数量，怎么做UAT？`，展示5类测试场景。

面试口径：这是基于ERP模拟业务规则和本地数据库做的作品集Agent，用来验证“业务问题→数据/规则证据→诊断/测试”的完整链路，不是SAP生产系统。
