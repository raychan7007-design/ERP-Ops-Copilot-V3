# 简历项目描述候选（仅在 Dify 部署完成前使用“本地可运行版本”口径）

**ERP Ops Copilot｜企业ERP智能运维与实施支持 Agent**

- 围绕采购验收、库存、销售出库等 ERP 场景设计 **Intent Router—RAG知识检索—只读SQL Tool—规则诊断—UAT辅助** 工作流，将业务规则与结构化业务数据联动，并输出可追溯依据与处理建议。
- 基于 SQLite/MySQL 兼容数据模型构建商品、采购单/明细、销售单/明细、库存及库存流水，封装**白名单参数化多表查询**，支持 PO/SO 状态诊断、SKU库存查询及来源流水追溯，避免由模型直接执行任意SQL。
- 建立 ERP 规则知识库与本地检索评测，覆盖分批验收、库存一致性、销售库存校验、权限与 Fit-Gap；通过自动化测试、固定回归及封存 Holdout 集验证路由、数据查询、诊断和UAT链路，并保留 Router/Tool/Retrieval Trace 便于解释与排错。
