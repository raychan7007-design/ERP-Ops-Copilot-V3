# 既有项目资产复用说明

ERP Ops Copilot 不是凭空造一套与原经历无关的系统，而是把此前已经深化过的两个项目能力串起来：

- **ERP Fit-Gap**：复用采购订单—分批验收—库存流水—销售履约的业务规则、状态流转和UAT思路。
- **智链进销存**：复用商品/订单/库存关系、SQL多表查询、库存流水与异常一致性思路。

本项目新增的是 Agent 路由、离线RAG、SQLite可查询演示库、PO/SO自动诊断、UAT Assistant、HTTP Tool接口和Dify配置规范。

真实性边界：这是2026-10独立作品集深化，不倒写成2026-03—04原课程项目当时已经具备的能力。
