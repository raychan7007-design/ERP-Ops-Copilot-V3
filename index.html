ERP Ops Copilot

ERP 智能运维与实施支持 Agent

面向 ERP 日常运维与实施支持场景构建的智能 Agent 原型， 将知识检索、ERP API/SQL 查询、业务规则判断、异常诊断与 UAT 辅助整合到统一工作流中。

Python ERP API SQL RAG Dify UAT

01｜项目目标

针对 ERP 支持过程中“问题定位依赖人工、业务规则分散、查询路径长”的场景， 设计 ERP Ops Copilot。用户以自然语言提出问题后，系统根据意图选择知识检索、 ERP 数据查询或异常诊断路径，并输出具有业务依据的处理结果。

02｜Agent 工作链路

用户问题 → 意图识别 / 路由
↓
RAG 知识检索 ｜ ERP HTTP API / SQL 查询 ｜ 业务规则诊断
↓
结果整合与依据返回
↓
异常处理建议 / UAT 辅助

03｜核心模块

知识检索 RAG

基于 ERP 运维知识与业务规则进行检索，为回答提供上下文依据。

ERP 数据查询

通过 API / SQL 查询订单、库存等业务数据，并形成结构化结果。

异常诊断

将库存、订单状态及业务规则组合，识别阻塞条件和异常原因。

UAT 辅助

围绕正常、异常及边界场景设计测试 Case，验证业务规则与接口返回。

04｜代表性业务 Case

库存不足诊断

当销售订单请求数量超过当前可用库存时，系统查询对应 SKU 库存， 结合业务规则返回 BLOCK 状态，并给出库存不足的诊断依据， 避免仅返回无解释的系统错误。

ERP 知识问答

对于流程、字段和异常处理类问题，Agent 优先检索知识库内容， 减少重复人工查询，并保留回答依据。

06｜项目定位

本项目为 ERP 智能运维与实施支持的可运行原型， 重点验证 Agent 与企业业务系统结合时的流程设计、数据查询、 异常诊断、知识检索及测试方法。
